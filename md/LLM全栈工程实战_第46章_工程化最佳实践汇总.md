## 03 十大黄金法则

1. **数据先于模型**：先做数据体检与清洗，再调参（04–10）；
2. **版本即生命线**：数据/模型/评测/部署全部版本化（04/41）；
3. **评测集先建并锁版**：先有“法庭”再开庭（20/44）；
4. **一次只变一个变量**：实验、消融、Canary 通用（18/44）；
5. **质量回归是底线**：换框架/量化/编译/模型都要跑回归（27–40）；
6. **先通后优、先云后自建**：最小闭环优先（02/42）；
7. **显存先算账**：权重/KV/优化器公式先算再花钱（12/33）；
8. **checkpoint 是保险**：挂了能无损续跑（13）；
9. **先恢复再查因**：线上故障先回滚再复盘（45）；
10. **复盘必须闭环**：badcase 回流评测与训练（44/45）。

## 05 分步实操：生成《落地手册》并自检（20 分钟）

### Step 1 手册生成器（10 分钟）

保存 scripts/build_handbook.py：

~~~python
# scripts/build_handbook.py —— 汇总模板资产生成《落地手册》
import pathlib

root = pathlib.Path(__file__).resolve().parent.parent
lines = ["# LLM 工业级全栈工程落地手册（Voice前沿）", "",
         "## 一、十大黄金法则", ""]
rules = [
    "1. 数据先于模型：先数据体检再调参（04–10 章）",
    "2. 版本即生命线：数据/模型/评测/部署全版本化（04/41）",
    "3. 评测集先建并锁版（20/44）",
    "4. 一次只变一个变量（18/44）",
    "5. 质量回归是底线（27–40）",
    "6. 先通后优、先云后自建（02/42）",
    "7. 显存先算账（12/33）",
    "8. checkpoint 是保险（13）",
    "9. 先恢复再查因（45）",
    "10. 复盘必须闭环（44/45）",
]
lines += [r + "" for r in rules]

lines += ["## 二、仓库模板资产（llm-demo）", ""]
assets = [
    ("数据管道", "data-pipeline/ 清洗/过滤/去重/脱敏/打分脚本"),
    ("数据集注册", "data/dataset_info.json"),
    ("训练配置", "configs/ 各阶段 YAML"),
    ("评测", "scripts/eval_suite.py + logs/eval_report_*.json"),
    ("发布", "release_manifest.json + release tag"),
    ("模型卡", "docs/model_card_*.md"),
    ("应急", "docs/incident_runbook.md"),
    ("优化清单", "logs/opt_checklist.md"),
    ("项目计划", "docs/*_project_plan.md"),
]
for name, path in assets:
    lines.append("- " + name + "：" + path)
lines.append("")

lines += ["## 三、新项目启动清单", ""]
checklist = [
    "□ 立项：能力清单+成功指标+路线决策（42）",
    "□ 数据：盘点/清洗/脱敏/评测隔离（04–10）",
    "□ 训练：SFT/对齐+调参+拟合诊断（14–26）",
    "□ 评测：dev/test 锁版+双证据（20/44）",
    "□ 部署：框架/量化/服务化（27–34）",
    "□ 优化：按 opt_checklist 选 2–3 项（35–40）",
    "□ 发布：manifest+Canary+回滚（41/44）",
    "□ 运营：监控 SLO+复盘闭环（45）",
]
lines += [c + "" for c in checklist]

out = root / "docs" / "LLM全栈工程落地手册.md"
out.write_text("\n".join(lines), encoding="utf-8")
print("handbook ->", out)
~~~

运行：

~~~bash
python scripts/build_handbook.py
cat docs/LLM全栈工程落地手册.md
~~~
