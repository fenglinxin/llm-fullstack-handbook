# LLM 全栈工程 · LLM 工业级全栈工程落地手册

> 零基础能看懂、工程师能直接复用、企业项目可落地的 LLM 工业级全栈工程连载手册。
> 第 00 章架构通识 + 主线 46 章，共 47 篇；单篇独立可读，合起来是一本完整手册。

### 三分钟跑通最小闭环（CPU）

```bash
cd code/minimind_style
pip install torch==2.2.2
python pretrain.py --steps 120      # 微型预训练
python train_sft.py --epochs 10     # 微型 SFT
python generate.py --prompt "人工智能"
```
